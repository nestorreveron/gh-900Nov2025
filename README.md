# 🏎️ Juego de Carros - Car Racing Game

Una aplicación web simple y divertida de juego de carreras de carros creada con HTML, CSS y JavaScript vanilla.

## 📝 Descripción

Este es un juego de carreras de carros donde el jugador debe esquivar los vehículos que vienen en sentido contrario. El objetivo es acumular la mayor cantidad de puntos posibles sin chocar con otros carros.

## 🎮 Características

- **Controles simples**: Usa las flechas del teclado (← →) o las teclas A/D para mover tu carro
- **Sistema de puntuación**: Acumula puntos mientras conduces
- **Velocidad incremental**: La velocidad aumenta progresivamente para mayor dificultad
- **Diseño responsivo**: Funciona en diferentes tamaños de pantalla
- **Interfaz intuitiva**: Botones para iniciar, pausar y reiniciar el juego

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador web
2. Presiona el botón "Iniciar Juego"
3. Usa las flechas del teclado o las teclas A/D para moverte entre los carriles
4. Evita chocar con los otros carros
5. ¡Intenta conseguir la puntuación más alta!

## 🎯 Instrucciones del juego

- Usa **← →** o **A/D** para mover el carro entre carriles
- Evita chocar con los otros carros
- Acumula puntos mientras conduces
- La velocidad aumenta cada 100 puntos
- El juego termina si chocas con otro vehículo
